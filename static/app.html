API 使用说明

认证方式

支持两种认证方式（任选其一）：

  • Authorization: Bearer sk-xxx — OpenAI 风格
  • x-api-key: sk-xxx — Anthropic 风格

对话补全 — OpenAI 格式

POST /v1/chat/completions
Authorization: Bearer sk-xxxxxxxx
Content-Type: application/json

{
  "model": "grok-4",
  "messages": [{"role": "user", "content": "Hello!"}],
  "stream": true
}

图片理解 (Vision)

在文本模型对话中发送图片，Grok 会理解图片内容进行回复。支持所有文本模型。

支持的图片格式：

  • HTTP/HTTPS URL — 自动下载并上传到 Grok
  • Base64 Data URL — data:image/jpeg;base64,...
POST /v1/chat/completions
Authorization: Bearer sk-xxxxxxxx
Content-Type: application/json

{
  "model": "grok-4",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "请描述这张图片"},
      {"type": "image_url", "image_url": {
        "url": "https://example.com/photo.jpg"
      }}
    ]
  }],
  "stream": true
}

Base64 直传图片：

// url 字段也可以直接传 base64 编码的图片
{"type": "image_url", "image_url": {
  "url": "data:image/jpeg;base64,/9j/4AAQ..."
}}

提示：content 可以是字符串或数组。使用数组格式时，可同时传入多张图片。 兼容 OpenAI Vision API 格式，支持 ChatGPT-Next-Web、OpenCat 等客户端。

对话补全 — Anthropic Messages 格式

POST /v1/messages
x-api-key: sk-xxxxxxxx
Content-Type: application/json

{
  "model": "claude-sonnet-4-20250514",
  "max_tokens": 8096,
  "messages": [{"role": "user", "content": "Hello!"}],
  "stream": true
}

Claude Code CLI 配置

在终端运行以下命令即可使用本代理：

# 设置环境变量
export ANTHROPIC_BASE_URL=https://你的域名
export ANTHROPIC_API_KEY=sk-xxxxxxxx

# 启动 Claude Code
claude

Claude → Grok 模型映射

  • claude-*-opus-* → grok-4-heavy（深度推理）
  • claude-*-sonnet-* → grok-4（标准）
  • claude-*-haiku-* → grok-4-fast（快速）
  • 其他 claude-* → grok-4（默认）
  • 原生 Grok 模型名称直接透传

支持的文本模型

  • grok-3 / grok-3-fast — Grok 3 系列
  • grok-4 / grok-4-fast / grok-4-heavy — Grok 4 系列
  • grok-4-mini — Grok 4 Mini（思维链）
  • grok-4.1 / grok-4.1-fast / grok-4.1-expert / grok-4.1-thinking — Grok 4.1 系列

图片生成（via Chat API）

POST /v1/chat/completions
Authorization: Bearer sk-xxxxxxxx
Content-Type: application/json

{
  "model": "grok-image-16_9",
  "messages": [{"role": "user", "content": "一只可爱的猫咪"}],
  "stream": true
}

支持的图片模型

  • grok-image — 1:1 默认
  • grok-image-1_1 / grok-image-2_3 / grok-image-3_2
  • grok-image-16_9 / grok-image-9_16

视频生成（via Chat API）
